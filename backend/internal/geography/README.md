# Справочник городов

`cities.json` — общий локальный справочник для Go и TypeScript. Нет геокодинга, внешних запросов при вводе и ключей API.

Источник: [HFLabs / city](https://github.com/hflabs/city/tree/ae661bffe572880472249097c9b29c42b09650ea), `city.csv`, 1117 записей. Исходная лицензия и лицензия производного файла данных: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Атрибуция: HFLabs, данные DaData и указанных в README источников. Изменения: оставлены имя, регион, ФИАС ID и население для сортировки; добавлены канонические строки для одноимённых городов и поисковые сокращения.

Это зафиксированный справочник, а не гарантия полного актуального реестра всех населённых пунктов. Неизвестное название в UI называется «не найдено в справочнике», а не «город не существует». При обновлении источника проверять переименования и совместимость сохранённых `value`.

Обновление: скачать и проверить новый CSV, затем `python3 scripts/data/import-cities.py /path/to/city.csv --commit SHA` из корня репозитория. Обновить источник в этом README и пересобрать backend/frontend вместе.

У одноимённых городов `value` содержит регион. Нельзя удалять уточнение или угадывать регион по первому совпадению. Старые названия без региона для таких городов пользователь должен выбрать заново. Сопоставление каталога остаётся точным: карточка с неоднозначным названием без региона не считается доказанным совпадением с конкретным городом.
