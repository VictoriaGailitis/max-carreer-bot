# Заполнение локального каталога программами VK

Вспомогательный сборщик читает публичные страницы VK и готовит JSON для существующего импорта каталога. Для запуска нужны Python 3.10+ и Docker Compose. На хосте Go не нужен.

## Запуск

Из корня репозитория:

```sh
make bootstrap  # только если локальный стенд ещё не настроен
make seed-vk
curl -fsS http://127.0.0.1:18080/readyz
```

`make seed-vk` собирает данные, собирает Docker-образ утилиты `ops`, проверяет весь JSON, запускает локальный стенд с миграциями и активирует каталог в PostgreSQL. Запуск разрешён для локального стенда с синтетическим токеном `local-only-*`.

Сбор без Docker и записи в БД:

```sh
make collect-vk
```

Результаты находятся вне Git:

- `.local/catalog/vk.json` — карточки в формате каталога версии 1;
- `.local/catalog/vk-report.json` — время проверки, URL и SHA-256 источников, соответствие направлений карточек направлениям приложения.

Повторный импорт уже собранного файла:

```sh
bash scripts/seed/vk.sh --file .local/catalog/vk.json
```

Импорт атомарно заменяет активный каталог целиком. Он не дописывает карточки к другому набору. Повторный импорт того же файла возвращает `catalog unchanged`; старые версии сохраняются в БД. Новый сбор обновляет `checked_at` и создаёт новую версию. При ошибке загрузки, изменении структуры источника или ошибке валидации активный каталог в БД сохраняется.

## Источники и поля

- [Видеокурсы](https://education.vk.company/centrum/video-courses) и страницы отдельных программ.
- [Стажировки](https://internship.vk.company/internship) и [каталог вакансий](https://internship.vk.company/vacancy), страницы отдельных стажировок.
- [VK Education Projects](https://education.vk.company/education_projects): одна карточка программы работы с кейсами. Содержимое берётся из публичного iframe этой страницы; отдельные кейсы не импортируются.
- [VK Education Practice](https://education.vk.company/program/vk_education_practice): учебная практика, тип `internship`.
- [Олимпиады](https://education.vk.company/centrum/olymp): образовательные программы и мероприятия, типы `course` и `event`.

Карточки имеют стабильные ID по идентификаторам источника. Программа, встречающаяся на нескольких страницах, импортируется один раз. Сохраняются заголовок, описание, условия участия, формат, города, стоимость/длительность при наличии, ссылки и явно указанные сроки записи. Дата начала записи не считается датой начала обучения; сроки, заданные только месяцем, остаются текстом.

Направления приложения сопоставляются по названию и направлению программы; это вспомогательная классификация для тестовой выдачи. Требования сохраняются текстом: сборщик не назначает уровни навыков или ограничения по обучению без структурированного соответствия. Неизвестные поля остаются `null`, пустым списком или `unknown`. Исходный HTML, cookies и состояние авторизации сайта в файлы не записываются.

Каталог содержит сведения из реальных источников и имеет `is_demo=false`, чтобы показываться в обычных API рекомендаций и карточек локального стенда. Перед публичным размещением карточки и их классификацию нужно проверить редакционно; этот инструмент предназначен для наполнения стенда до появления админ-панели компаний.

## Проверки и устройство

```sh
make check-seed
```

Проверки работают без сети: изменение схемы источника, дедупликация, нормализация дат, обработка iframe, допустимые домены и сохранность прежних файлов при ошибке сбора.

- [Сборщик](../scripts/seed/vk_catalog.py) — только стандартная библиотека Python, таймауты, повторы временных ошибок, ограничение размера ответа и доменов переходов.
- [Сценарий запуска](../scripts/seed/vk.sh) — сбор, проверка и импорт через существующий `cmd/ops`.
- [Compose overlay](../deploy/compose.tools.yaml) — одноразовый контейнер импорта с доступом к локальной БД.

Обычный `make up` сборщик не запускает. Обновление каталога выполняется вручную.
